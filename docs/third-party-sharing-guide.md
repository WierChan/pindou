# 第三方分账：选机构、签约、商家进件（运营操作指南）

2026-09-18 起，代拼订单的收款与分账改走**持牌第三方支付机构**（下称「支付机构」）。
原因：微信直连分账上限 30%，提额申请会被按「平台统收涉及二清」拒绝；服务商模式要在付款那一刻定商家，和我们「先付款、后台再人工派单」的流程冲突。
客户那边没有任何变化，照旧在小程序里用微信支付付款。变的是钱的去向：进支付机构在银行的监管专户，订单完成后由支付机构分给商家和平台。
后端规则见 `docs/order-api.md` §6，微信直连的老方案留档在 `docs/wxpay-profitsharing-guide.md`。

## 1. 我们要的能力（拿去逐条问每一家，缺一条换下一家）

| 必须有 | 为什么 |
|---|---|
| 央行《支付业务许可证》在有效期内，含「互联网支付」 | 没牌照的只是渠道商，钱在谁的专户、出事找谁都说不清 |
| 微信小程序支付，能绑定我们的 AppID `wx483d6f0b4bf6eaec` | 客户还是用微信付 |
| 先收后分 / 延时分账：付款时不指定商家，钱先冻着，订单完成再分 | 我们付款后才人工派单 |
| 分账比例可到 100%，平台留 10%、商家拿 90% 不用另外审批 | 微信直连卡的就是这个 |
| 商家能以个体工商户或小微（身份证 + 银行卡）进件 | 合作商家多是个体户，以后可能有个人 |
| 未分账订单可全额原路退款 | 客户在商家发货前退款 |
| 支付、分账、退款都有异步回调，有每日对账文件 | 后端要靠这个落状态、对账 |

| 加分项 | 说明 |
|---|---|
| 已分账订单支持分账回退 | 没有就按合作协议 6.3 走线下 |
| 有沙箱环境 | 后端联调不用花真钱 |
| 商家进件有接口，或至少有网页让商家自己填 | 免得我们代收身份证照片 |
| 结算 T+1 到商家银行卡 | 商家关心到账速度 |

要问清的价格：微信渠道费率（标准 0.6%，谈到多少写进 `order.pricing.feeRate`）、分账是否另收费（按笔或按比例）、提现 / 结算手续费、开户费或年费、延时分账最长几天。

## 2. 候选机构与怎么核牌照

常见做平台分账的持牌机构：汇付天下（产品叫「斗拱」）、富友支付、易宝支付、通联支付。都是央行持牌，各家销售联系方式在官网。
核牌照：中国人民银行官网 → 政务公开 → 行政审批公示 → 「已获许可机构（支付机构）」，查机构全称，看许可业务里有没有「互联网支付」、有效期到哪年。
市面上叫「XX 分账链」「XX 云分账」的多是渠道商，可以用，但要问清：背后是哪家持牌机构、合同和谁签、钱在谁名下的专户、出问题谁负责。

## 3. 平台接入步骤

1. **商务沟通**：发一段业务说明给对方——拼豆代拼平台，客户在小程序微信支付下单，平台后台派单给合作商家，订单完成后分账商家 90%、平台 10%，商家为杭州的个体户 / 个人，月单量预估。对方会给方案和报价。
2. **签约 + 平台进件**：营业执照、法人身份证正反面、对公账户、小程序截图与 AppID、ICP 备案信息。一般 3～7 个工作日。
3. **绑定小程序 AppID**：机构会给指引。通常是机构在它的微信支付服务商后台把我们的 AppID 关联到分给我们的子商户号，需要小程序管理员微信扫码确认。
4. **拿密钥**：机构给的商户号、API 密钥或证书、回调验签公钥。**交后端，走私密渠道**。这和微信商户平台那套 APIv3 密钥无关，别混。
5. **后端接入 + 沙箱联调**：按 `docs/order-api.md` §3.1 / §3.7 / §6 实现；`PAY_MOCK` 关掉前先在沙箱跑通。
6. **1 元真实单验收**：支付 → 后台派单 → 完成 → 分账 → 商家银行卡到账 90% 净额；再下一单在发货前退款，钱原路回到客户微信。两条都过了再把代拼入口对外开。

## 4. 商家进件步骤（每家一次）

| 商家类型 | 材料 | 商家本人要做 |
|---|---|---|
| 个体工商户 | 营业执照、经营者身份证正反面、经营者本人名下借记卡 | 短信验证码，部分机构要人脸 |
| 个人（小微） | 身份证正反面、本人名下借记卡 | 同上 |

流程：商家签好合作协议、填好附件二 → 运营在管理后台「商家管理」录入商家 → 点「发起进件」（机构有接口时后端直接提交；只有网页进件的，让商家在机构页面自己填，运营把结果手填回后台）→ 进件状态变「已进件」后才能派单。
身份证、执照照片不要存在我们的后台或聊天记录里，用机构的进件页面直接传。

## 5. 合作协议对应改动（已改，`docs/拼豆代拼合作协议模板.docx`）

- 3.1 收款方改为支付机构监管专户，平台不触碰资金。
- 3.2 分账改为通过支付机构，手续费按机构合同费率，商家 90% / 平台 10% 不变；乙方义务改为配合进件、维护结算卡。
- 3.3 结算到商家银行卡，T+1；保底分账按机构延时分账期限。
- 6.3 退款：未分账原路退；已分账机构支持回退则回退，否则商家退给平台。
- 附件二改为「结算账户（支付机构进件）及自取信息」：进件类型、执照 / 身份证、结算卡、预留手机。

## 6. 时间线（顺序做，能并行的并行）

| 事 | 谁 | 大约 |
|---|---|---|
| 问 2～3 家、拿报价、定一家 | 运营 | 3～5 天 |
| 签约 + 平台进件 + 绑 AppID | 运营 | 1～2 周 |
| 商家签协议、进件 | 商家 + 运营 | 和上面并行，1～3 个工作日 |
| 后端接机构 SDK、沙箱联调 | 后端 | 1～2 周，签约后拿到文档就能开始 |
| 1 元真实单验收 | 运营 + 后端 | 1 天 |

签约那周就把机构的对接文档转给后端，不要等平台进件完。

## 7. 上线前检查

- [ ] 机构合同费率已写进后台「代拼配置」的报价覆盖（`feeRate`），小程序冷启动后下单页金额和后台分账预估一致。
- [ ] 至少一家商家进件状态「已进件」，派单下拉里能选到。
- [ ] 1 元单：支付、派单、完成、分账、到账全通；另一单发货前退款全通。
- [ ] 机构回调地址已加到后端 HTTPS 域名，小程序后台 request 合法域名不用改（客户端只连我们自己的域名）。
- [ ] `PAY_MOCK` 关闭，小程序 `utils/env.js` 切正式。
- [ ] 后台「代拼配置」代拼入口打开。

## 8. 打电话问什么（每家都按这张问，答案填进 §6.0 的表）

开场一句话：「我们是杭州的小程序平台，客户在小程序里微信支付下单，平台后台派单给杭州的个体户商家做，订单完成后分账商家 90%、平台 10%，月几百单，要接小程序支付和延时分账，请转商务。」

**资质**
1. 有央行《支付业务许可证》吗，含互联网支付吗？合同和谁签，客户的钱在谁名下的备付金账户？
2. 平台主体是有限公司，进件要哪些材料，几个工作日？

**能力（有一条不行就换家）**
3. 支持微信小程序支付吗？绑定我们的 AppID 怎么操作，要小程序管理员做什么？
4. 延时分账：付款时可以不指定分账方吗？最长能挂多少天？到期没分会怎样？
5. 分账比例有没有上限？商家 90%、平台 10% 要不要另外审批？
6. 分账接收方：个体户能进件吗？没执照的个人能吗？各要什么资料，本人要做什么验证？有没有单笔、单日、单月限额？
7. 一笔订单能同时分给商家和平台两个接收方吗？平台那 10% 是自动留存还是也要作为接收方？
8. 退款：未分账的能全额原路退吗？已分账的能回退吗？
9. 支付、分账、退款、进件结果都有异步回调吗？有每日对账文件吗？
10. 商家分到的钱 T+几 到银行卡？平台的钱 T+几？能自动结算吗？

**费用**
11. 微信小程序渠道费率多少？标准 0.6%，能不能低一点？
12. 分账另外收费吗，按笔还是按比例？
13. 结算 / 提现手续费多少？
14. 开户费、年费、保证金、最低交易量有没有？
15. 沙箱免费吗？

**接入**
16. 开发文档公开吗，有哪些语言的 SDK？沙箱怎么开？
17. 有技术支持群或对接人吗？
18. 从签约到能收第一笔钱通常几周？

**合同与风险**
19. 合同期限多长，怎么退出，退出时未结算的钱怎么处理？
20. 什么情况下会冻结商家或平台的资金，冻结后怎么解？
21. 手续费能开发票吗，开什么类型？

**挂电话前要拿到三样**：对接文档链接、合同样本、书面报价单。再加对方微信，后面技术问题让后端直接问。
